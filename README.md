## 🌌 About MarsNavig

MarsNavig is an automated navigation system project designed around a modern web experience.

Built using React, TypeScript and Vite, the project provides a foundation for developing an intelligent navigation experience with Google Gemini API integration.

**Mission:** Explore new possibilities in intelligent navigation through modern technology.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm or Bun
- Git

### 1. Clone the repository

```bash
git clone https://github.com/biswojitsamal2008/MarsNavig.git
```

### 2. Enter the project directory

```bash
cd MarsNavig
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🏗️ Production Build

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

Run TypeScript checks:

```bash
npm run lint
```

## 🔐 Environment Configuration

The repository includes an `.env.example` file.

Configure the required environment variables using the appropriate secure environment configuration for your runtime.

- `GEMINI_API_KEY` — Gemini API authentication.
- `APP_URL` — Application hosting URL.

**Security:** Never commit actual API keys, passwords or private credentials to GitHub.

A static GitHub Pages deployment cannot independently provide a secure server-side Gemini API key. AI features requiring private credentials need a secure backend or another supported runtime.
